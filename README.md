# lorenzGNN

## Setup
* create a virtual environment, e.g.
  ```
  pip install virtualenv
  virtualenv venv
  ```
* activate the virtual environment (in this example the environment name is venv)
  ```
  source venv/bin/activate
  ```
* install the required packages inside the virtual environment:
  ```
  pip install -r requirements.txt
  ```

## Data Paths
* change all data paths to the path relevant to your computer
  - look for variables like `DATA_DIRECTORY_PATH`, `data_path`, `CHECKPOINT_PATH` and replace their contents appropriately
